# FPS Unlocker for DBZK (HD Version)
An open-source .ASI mod that removes the 60 FPS cap for **Dragon Ball Z: Kakarot (HD Version)**

**Note:** AI assistance was used for some functions and bug fixes.

A huge thank you to **Gantz79**. If it weren't for the Cheat Engine Table he created, I wouldn't have been able to make this mod.

https://www.nexusmods.com/profile/Gantz79

You need to place the mod file, along with the **Ultimate ASI Loader .DLL** file, in the `DRAGON BALL Z KAKAROT\DLC\Remaster\AT\Binaries\Win64` folder of your game.

You can download the latest version of **Ultimate ASI Loader** here:

https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases/download/x64-latest/winmm-x64.zip
